## 🧑‍💻 &nbsp;Sobre mim

<img align="right" width="370" src="https://raw.githubusercontent.com/MicaelliMedeiros/micaellimedeiros/master/image/computer-illustration.png" alt="ilustração de um computador"/>

Olá! Sou o **Diógenes**, de Porto Alegre 🇧🇷. Trabalho com **Visão Computacional** na **NexAI**, onde ensino máquinas a enxergar — e, no caminho, descobri que gosto tanto de **construir o modelo** quanto de **construir a infraestrutura que o sustenta**.

Minha rotina vive entre três mundos: o **Python** que processa frames e roda inferência, o **Terraform** que descreve a nuvem onde isso tudo vai parar, e os **testes** que garantem que nada quebre no caminho. Acredito que infraestrutura boa é a que cabe num `git diff`, e que código sem teste é só uma hipótese.
